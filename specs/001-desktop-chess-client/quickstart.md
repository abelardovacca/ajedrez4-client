# Quickstart: Desktop Chess Client

**Feature**: `001-desktop-chess-client`  
**Date**: 2026-05-02  
**Language**: Python 3.11+ with Pygame 2.x

---

## Prerequisites

- Python 3.11 or later (check: `python3 --version`)
- pip (usually bundled with Python)
- ajedrez4-server running locally (default `http://localhost:8080`)

---

## Setup

### 1. Clone & Navigate

```bash
cd ajedrez4-client
```

### 2. Create Virtual Environment

```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

**Contents of requirements.txt** (to be maintained):

```
pygame==2.1.2
requests==2.28.0
python-dotenv==0.20.0
pytest==7.2.0
pytest-asyncio==0.20.0
mypy==0.990
black==22.12.0
```

### 4. Configure Server URL (Optional)

Create a `.env` file in the project root:

```
SERVER_URL=http://localhost:8080
POLLING_INTERVAL=1.5
DEBUG=false
```

If not provided, defaults to:
```
SERVER_URL=http://localhost:8080
POLLING_INTERVAL=1.5
```

## Running the Client

### Development Mode

```bash
python3 -m src.main
```

Or with Pygame debug output:

```bash
SDL_VIDEODRIVER=windowed python3 -m src.main
```

### Building a Standalone Executable (Optional)

With PyInstaller (install: `pip install pyinstaller`):

```bash
pyinstaller --windowed --icon=src/assets/icon.png --name ChessClient src/main.py
```

Output: `dist/ChessClient/` (Windows), `dist/ChessClient.app` (macOS), `dist/ChessClient` (Linux)

## Configuration Reference

### Environment Variables

| Variable | Default | Purpose |
|----------|---------|---------|
| `SERVER_URL` | `http://localhost:8080` | ajedrez4-server base URL |
| `POLLING_INTERVAL` | `1.5` | Lobby/game polling interval (seconds) |
| `DEBUG` | `false` | Enable debug logging to console |
| `WINDOW_WIDTH` | `1024` | Initial window width (pixels) |
| `WINDOW_HEIGHT` | `768` | Initial window height (pixels) |

```bash
SERVER_URL=http://192.168.1.100:8080
POLLING_INTERVAL=2.0
DEBUG=true
```

## Troubleshooting

### "Server unreachable" on startup

1. Check that ajedrez4-server is running: `curl http://localhost:8080/games` (should return 401 if auth headers missing, but confirms server is up)
2. Verify SERVER_URL environment variable: `echo $SERVER_URL`
3. If on different machine, set `SERVER_URL=http://<server-ip>:8080` in .env

### "Invalid move syntax" when submitting a move

- Moves must be in UCI notation: `e2e4`, `e7e8q` (with promotion)
- Ensure click-drag is correctly converting pixel coordinates to squares

### Tests fail with "Connection refused"

- For contract tests: should not require server (uses mocked responses). Check that mocking is properly configured.
- For integration tests: ensure ajedrez4-server is running on `http://localhost:8080`

### Pygame display issues on macOS

If using an older macOS or headless environment:

```bash
export SDL_VIDEODRIVER=dummy
python3 -m src.main
```

(This disables rendering but allows testing logic.)

## Development Tips

### Adding a New Screen

1. Create `src/ui/screens/new_screen.py` with a class inheriting from `Screen`
2. Implement `render(pygame_surface)` and `handle_event(event)` methods
3. Update state machine in `src/state/state_machine.py` to transition to it
4. Add unit test in `tests/unit/test_state_machine.py`

### Debugging HTTP Requests

Enable debug logging:

```bash
DEBUG=true python3 -m src.main
```

This will print all HTTP requests/responses to the console.

### Asset Pipeline

1. Author pixel-art sprites in Aseprite or Piskel
2. Export as PNG (one file per sprite)
3. Place in `src/assets/sprites/`
4. Reference in `src/ui/theme.py` or component code
5. Ensure sprite size matches rendering code (e.g., 64×64 for board squares)

## Next Steps

After setup:

1. **Verify server is running**: `curl http://localhost:8080/games` should return 401 (need session ID)
2. **Run the client**: `python3 -m src.main`
3. **Create a session**: Type a username and press "Play"
4. **Verify lobby loads**: You should see an empty game list or existing games from the server
5. **Create a test game**: Click "New Game" and confirm the waiting screen appears
